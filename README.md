# Індіана Джонс і останній прямокутний обхід

**Код задачі:** `IJONES`

В пошуках Святого Грааля Індіана Джонс зіткнувся з небезпечним випробуванням. Йому потрібно пройти крізь прямокутний коридор, який складається з крихких плит (пригадайте сцену з фільму «Індіана Джонс і останній хрестовий похід»). На кожній плиті написана одна літера.

### Умови проходження
* **Початок:** Можна починати з будь-якої плити в найлівішому стовпці.
* **Вихід:** Виходом із коридору є верхня права та нижня права плити.
* **Рух:** Індіана спритний і може переходити не лише на сусідню плиту, а й перестрибувати через кілька плит. Проте, щоб не провалитися крізь підлогу, він повинен дотримуватися таких правил:
    1.  Після кожного кроку Індіана повинен опинятися **правіше**, ніж був перед цим (індекс стовпця має збільшитися).
    2.  Завжди можна переходити на одну плиту **безпосередньо праворуч** (в той самий рядок, наступний стовпець).
    3.  Крім руху на одну плиту праворуч, можна перестрибувати на **будь-яку іншу плиту з такою самою літерою**, за умови, що вона знаходиться правіше.

**Завдання:** Для заданого коридору підрахуйте, скільки всього існує способів пройти його успішно.

---

### Вхідні дані
Вхідний файл `ijones.in` складається з `H + 1` рядків:
* Перший рядок містить два числа `W` і `H`, розділені пробілом: 
    * `W` — ширина коридору ($1 \le W \le 2000$);
    * `H` — висота коридору ($1 \le H \le 2000$).
* Кожен з наступних `H` рядків містить слово довжиною `W` символів, яке складається з малих латинських літер від `a` до `z`.

### Вихідні дані
Вихідний файл `ijones.out` повинен містити одне ціле число — кількість різних шляхів для виходу з коридору.
